# Запуск готового квеста

1. Запустите `start-windows.bat` или `npm start` и откройте http://localhost:3000.
2. Альтернатива без установки: откройте `play-offline.html`. Все изображения уже встроены.
3. Для проверки используйте START-LION, GIFT-ONE, GIFT-TWO и LAST-SECRET.

Визуальная сборка завершена: искать и размечать скриншоты для запуска не требуется. Интернет для игры не нужен.

Перед настоящим праздником замените демонстрационные загадки, коды и места подарков в `config.js` по `docs/CUSTOMIZATION.md`. После изменения выполните `npm run validate` и `python build_standalone.py`, чтобы обновить автономную страницу. Если Python не установлен, обычный запуск через `npm start` сразу использует новый конфиг.

Карточки организатора: `npm run print:cards`. Экспорт прогресса: Wallet → Export Save. Все коды находятся в клиентском исходнике; это персональный домашний квест.
