# GW2 Black Lion Gift Quest — v1.0

**Рабочий статический фан-квест на одного игрока**, оформленный в стиле инвентаря Guild Wars 2. В прототипе есть Black Lion Chest, магазин ключей, ввод бумажных кодов, ручная продажа мусора, обмен золота на кристаллы, читаемые книжки и секретный финал. Никаких реальных покупок.

## Запуск

- Самый быстрый просмотр — **`play-offline.html`**. Всё необходимое для игры уже встроено в HTML. Поддержка `localStorage` при открытии с `file://` может различаться между браузерами.
- Рекомендованный запуск — `npm start`, затем `http://localhost:3000`. Требуется Node.js 18+. Альтернатива: `python3 -m http.server 3000` из папки проекта.
- Проверки: `npm test` и `npm run validate`.

Демо-коды: `START-LION`, `GIFT-ONE`, `GIFT-TWO`, `LAST-SECRET`. Настоящие коды и загадки заменяются в `config.js` (инструкция: `docs/CUSTOMIZATION.md`).

## Механика

1. В начальном инвентаре находится количество одинаковых сундуков, соответствующее числу подарков `gifts`.
2. Каждый основной код даёт **100 кристаллов**. Ключ стоит **100 кристаллов**.
3. За открытие обычного сундука выдаются **ровно четыре предмета**: сюжетная книга, мусор, материал, коллекционный трофей.
4. Мусор продаётся вручную через Merchant. Суммарная стоимость всего мусора — **90 серебра**, после обмена — **90 кристаллов**.
5. Отдельный секретный код `LAST-SECRET` даёт недостающие **10 кристаллов**. После покупки дополнительного ключа неожиданно появляется бонусный сундук с легендарной книжкой.

Порядок кодов не проверяется. Физически они должны выдаваться последовательно. Если игрок знает все коды заранее, он может накопить несколько ключей — для домашнего квеста это допустимо.

## Управление

- `I` — инвентарь, `O` — магазин, `M` — переключить звук, `Esc` — закрыть окно.
- Двойной клик — действие с предметом, ПКМ — меню, наведение — описание предмета.
- На телефоне: касание и кнопка `Use / Read`, длинное нажатие для меню.
- В книге `←` и `→` перелистывают только **уже полученные** книги.

## Экспорт и импорт сохранения

Откройте **Wallet → Export Save**, чтобы скачать `black-lion-quest-save.json`. Для восстановления откройте **Wallet → Import Save**, выберите файл и подтвердите замену локального прогресса. Файл остаётся на вашем устройстве, сервер не используется.

Восстановление разрешено только для **той же конфигурации**: число и ID подарков, коды, экономика и тексты загадок должны совпадать. Это предотвращает перенос старого прогресса в новый вариант квеста. Перед изменением текста книжек, пожалуйста, сохраните отдельную копию конфига.

## Иконки и лицензии

Когда сайт запущен с `http://` или `https://`, браузер может загрузить официальные значки сундука, ключа и некоторых материалов из публичного [Guild Wars 2 API](https://wiki.guildwars2.com/wiki/API:2/items) по ID 20316, 19980, 24272, 19703, 24273 и 24295. При отсутствии сети показываются **локальные оригинальные SVG-иллюстрации прототипа**. В ZIP официальные изображения не вложены; иконки получаются по URL от ArenaNet без перепаковки и изменения.

Никакие введённые коды, балансы или сохранения не передаются в GW2 API — запрашиваются только публичные метаданные нескольких игровых предметов. Во время разработки изолированная среда не позволила проверить сетевую загрузку, но работа офлайн проверена.

## Завершённая визуальная часть v1.0

- Компактный HUD с кнопками Inventory, Merchant, Black Lion, Wallet в верхнем левом углу и счетчиками валют в правом. Старую веб-шапку убрали.
- Игровая панель навыков, сфера здоровья, портрет персонажа, художественная мини-карта как **декоративные** элементы; на мобильном остаётся доступная нижняя навигация.
- Более узкие отступы и сетка, мягкие полупрозрачные рамки, фактуры окон, новые состояния для окон Black Lion Chest и наград.
- Опциональные официальные иконки нескольких материалов по GW2 API на HTTP(S); локальная иллюстрация при отсутствии сети.
- Сохранились экономика, книжки, ручная продажа, импорт/экспорт сохранения и скрытый финал; старое состояние localStorage не сбрасывается.
- Скриншоты после браузерной проверки в `previews/`; подробности — `VISUAL_FINISH.md`.

### Что это НЕ означает

Это фан-воссоздание с собственными иллюстрациями, а не буквальная пиксельная копия и не исполняемая игра GW2. Прямую встроенную копию проприетарных текстур/звуков не делали. Встроенные загадки и коды пока демонстрационные. Настоящие подарки можно настроить позже.

- Награды появляются последовательно, **книжка — последней**. Каждый предмет из окна наград можно открыть для просмотра; книжка читается отдельной кнопкой. Легендарная книжка получила усиленное оформление.
- Вместимость сумок автоматически подстраивается под количество подарков.
- **Печатные карточки с промокодами:** выполните `npm run print:cards`. HTML будет создан за пределами папки сайта; раздайте карточки по сценарию из `docs/PRINTABLE_CODES.md`. Это инструмент организатора на командной строке, **не админка**.
- Добавлены тесты с 1, 2, 5, 10 и 30 подарками. В любом случае все обычные сундуки дают суммарно ровно 90 серебра, а секретный код — 10 кристаллов.
