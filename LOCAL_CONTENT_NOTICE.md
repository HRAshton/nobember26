# Local content and licensing

No copyrighted Guild Wars 2 UI screenshots, extracted game textures, or sound recordings are included in this package. It ships the existing original fan-style prototype and local asset processing tools only. Artwork supplied later by a user is processed exclusively on the user's own computer; no assets are uploaded to a generative AI service. Use of game content remains subject to ArenaNet's user agreement and content policy; a private GitHub repository and a LAN site do not waive licensing conditions. Fan projects must identify themselves as unofficial and noncommercial, and must contain original creative contribution.

- https://www.arena.net/en/legal/content-terms-of-use
- https://www.arena.net/en/legal/user-agreement

Do not distribute the tool output as a standalone game-art pack, and review permissions before pushing asset files even to a private repository. The repo `.gitignore` ignores user captures, resulting PNGs and the standalone HTML (which may embed artwork). No upload, AI editing, extraction from Gw2.dat, game automation or bypass of game protections occurs within this package.
