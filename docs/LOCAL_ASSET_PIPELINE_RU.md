# Локальное завершение визуального слоя — инструкция

## Что делает автоматизация

Этот набор продолжает **рабочую v1.0**. Он не переписывает квест, экономику 100/90/10, код активации, торговца, книги и localStorage. Добавлены: CSS-скин с текстурами, подмена иконок на локальные PNG, скрипты нарезки и проверка результата.

**Оригинальных ресурсов ArenaNet в поставке нет**. Никаких изображений не загружается в ChatGPT, ИИ или сторонний сервер. Если предоставлены готовые вырезанные файлы, интеграция запускается полностью автоматически. Для больших скриншотов без разметки один раз требуется разметить области: инструменты не способны достоверно угадать границы UI из произвольного игрового кадра.

## Быстрый способ — уже нарезанные PNG

1. Скопируйте PNG в `local-input/ready-slices/`.
2. Используйте **строго такие имена**, если элемент есть: `window_frame.png`, `window_title.png`, `slot_empty.png`, `hud_top.png`, `button.png`, `chest_panel.png`, `merchant_panel.png`, `trading_panel.png`, `inventory_panel.png`, `wallet_panel.png`, `world_background.png`, `book_pages.png`, `tooltip.png`, `menu_bar.png`.
3. Иконки именуются `item_chest.png`, `item_key.png`, `item_gem.png`, `item_book-1.png`, `item_material-ore.png`, `item_junk-seal.png` и т.п. Полный список — в `tools/finish_local.py`, константа `ITEMS`.
4. Проверьте `python3 tools/finish_local.py --check`.
5. Запустите **Windows:** `finish-windows.bat` или **macOS/Linux:** `./finish-mac-linux.sh`.
6. Запускайте сайт штатно: `npm start` и откройте `http://localhost:3000` (либо `./start-mac-linux.sh`).

`--strict` требует шесть ключевых слоёв: `window_frame`, `window_title`, `slot_empty`, `chest_panel`, `merchant_panel`, `trading_panel`. Если чего-то не хватает, команда завершается с объяснением; можно сделать частичную сборку вручную, убрав `--strict`.

## Если есть только цельные скриншоты

1. Снимите кадры **в своём клиенте игры**, в одном разрешении и с одинаковым масштабом интерфейса. Желательно без курсора, тултипов, предметов поверх пустых областей, без личных данных. Сохраняйте в PNG.
2. Откройте локально `tools/calibrate.html` обычным браузером. Выберите файлы, по очереди указывайте элемент и выделяйте его прямоугольник. Это интерактивная разметка, не загрузка на сайт.
3. Скачайте `slices.local.json`. Положите файл в `local-input/slices.local.json`. Поместите исходные скриншоты (с теми же именами!) в `local-input/screenshots/`.
4. Запустите `python3 tools/finish_local.py --strict --standalone` и проверку `python3 tools/create_contact_sheet.py`.
5. Посмотрите на результат в браузере. Если рамка растягивается неправильно, выделите её заново или задайте `9-slice` как четыре толщины сторон: `лево,верх,право,низ`. Повторный запуск перегенерирует файлы.

Формат JSON:

```json
{
  "version": 1,
  "regions": [
    {"name":"window_title","file":"inventory.png","rect":[50,60,360,36]},
    {"name":"window_frame","file":"inventory.png","rect":[30,30,430,460],"slice":[20,20,20,20]}
  ]
}
```

Это **пример координат**, не координаты реального скриншота. Готовый шаблон также есть в `local-input/slices.example.json` — перед запуском его нужно адаптировать и сохранить как `slices.local.json`. Формат прямоугольника: `[x, y, ширина, высота]` в пикселях оригинала. Области надо разметить под свой кадр.

## Какие изображения подходят

| Имя | Что выделять | Правило |
|---|---|---|
| `window_frame` | пустая фактурная панель с углами | допускает растяжение 9-slice; не брать текст и предметы |
| `window_title` | только фон строки заголовка | текст заголовка рисует HTML |
| `slot_empty` | один пустой слот | квадрат без предмета и цифры |
| `hud_top` | однородная полоска HUD | можно растягивать |
| `button` | чистая кнопка | надпись рисует HTML |
| `chest_panel` | подложка окна сундука | не захватывать видимые загадки |
| `merchant_panel` | подложка торговца | без NPC-имени/цифр |
| `trading_panel` | подложка BLTC | без цен и товаров |
| `item_chest`, `item_key` | готовые отдельные изображения | квадрат/прозрачность, без лишнего фона |

Если скриншот содержит надписи/монеты/предметы, их вырезка приведёт к **двойному тексту** при интерактивной отрисовке. Используйте пустые области или отдельные оригинальные UI-текстуры, если на них есть право.

## Дополнительная опция: оригинальные иконки через API

Запустите на своём компьютере `python3 tools/fetch_api_icons.py`. Скрипт получает **публичные метаданные** `api.guildwars2.com/v2/items` и скачивает отдельные иконки с `render.guildwars2.com` в `local-input/ready-slices/`. Он ничего не отправляет, не спрашивает API-ключ и не перезаписывает существующие файлы. Нужен интернет; ошибки сети не влияют на работу локальных SVG.

Потом снова выполните `python3 tools/finish_local.py --standalone`. Существующие файлы PNG в `ready-slices` имеют приоритет над координатами из JSON.

## Что будет автоматически создано

- `assets/real-ui/*.png` — локальные нарезанные изображения;
- `assets/real-ui/skin.css` — CSS для окон и HUD;
- `assets/real-ui/asset-map.js` — карта заменяемых иконок;
- `assets/real-ui/asset-report.json` — список источников и SHA-256;
- `assets/real-ui/contact-sheet.png` — картинка для быстрой визуальной проверки;
- `play-offline.html` — офлайн-страница с инлайновыми локальными ассетами, если указан `--standalone`.

Ни входные скриншоты, ни выходные PNG не коммитятся по умолчанию (`.gitignore`). При необходимости для частной локальной сборки перенесите полученный каталог **целиком**. Проверьте условия использования до копирования или публикации.

## Тестирование

`npm test` — исходные 30 тестов экономики и UI. `python3 tools/finish_local.py --check` — готовность входных изображений. `python3 tools/create_contact_sheet.py` — визуальный контактный лист. Посмотреть в Chrome/Firefox минимум: Inventory, Black Lion Chest, Merchant, Trading Company, книжку и легендарную награду. Игра должна остаться интерактивной. Возможность отменить визуальный скин: удалить строку `<link rel="stylesheet" href="./assets/real-ui/skin.css">` из `index.html`; исходные CSS и логика останутся нетронутыми.

## Запуск по локальной сети

`npm start` использует встроенный `server.cjs`, который обычно слушает на сетевых интерфейсах (порт 3000). Адрес устройства: `http://IP_КОМПЬЮТЕРА:3000`. Не открывайте порт в интернет, если квест содержит секреты. Устройства в локальной сети имеют **раздельный localStorage**: прогресс игрока живёт в том браузере, где он играет; для переноса предусмотрен Wallet → Export/Import Save. Без сервера всё равно нельзя надёжно скрыть содержимое будущих загадок от разработческих инструментов браузера.
