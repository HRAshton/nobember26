# Asset references

- Hardstuck, [Game basics](https://hardstuck.gg/gw2/guides/general/game-basics-first-steps-in-tyria/): inventory4.jpg, interface2.jpg, intro-minimap.jpg. Crops provide slots, bags, journals, wallet and menu icons, and skill images.
- Hardstuck, [Gemstore overview](https://hardstuck.gg/gw2/guides/general/gemstore-overview/): Gem_highres.png.
- RPG Site, [Guild Wars 2 Review](https://www.rpgsite.net/review/3154-guild-wars-2-review): Lions_Arch_04.jpg, the old Lion's Arch background.
- [GW2.app](https://gw2.app/items/20316): individual item pages supply direct image links for the chest, key, and materials.
- [Blish HUD](https://github.com/blish-hud/Blish-HUD): window, titlebar, tooltip, health, parchment, and button textures. Its license is retained in BLISH_HUD_LICENSE.txt.

ASSET_SOURCES.json lists each source page, direct image URL where applicable, crop rectangle, and source SHA-256. assets/real-ui/asset-report.json records the compiled crop hashes.

The minimap crop shows Queensdale and is decorative. Quest journals and trophies reuse suitable visual motifs. Their game behavior is defined by this project's configuration.

[GW2 Treasures, Bottle of Choya...Perfume?](https://en.gw2treasures.com/item/84591) supplies the game reference and direct image URL for the new perfume reward icon.
